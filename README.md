# FAQ-бот для репетиции хакатона

Консольный чат-бот на Python, отвечающий на ключевые организационные вопросы участников репетиции (время проведения, состав команды, треки, сдача проекта и призы).

---

## 📌 Что получилось

1. **База знаний (`faq.txt`)**: содержит 5 структурированных пар «вопрос–ответ» по ключевым темам репетиции.
2. **Логика сопоставления (`bot.py`)**:
   - Токенизация и очистка запроса от знаков препинания и стоп-слов.
   - Поиск по ключевым словам и основам слов (стеммам) для каждой из 5 тем.
   - Оценка нечеткого сходства (fuzzy matching) через стандартную библиотеку `difflib` для устойчивости к падежам и синонимам.
   - Пороговая фильтрация: если запрос не относится ни к одной теме, бот отвечает: *«К сожалению, я не знаю ответа на этот вопрос.»*
3. **Автономность**: работает исключительно на стандартной библиотеке Python 3 без сторонних зависимостей (`pip install` не требуется).

---

## 🚀 Как запустить

### Требования
- Установленный **Python 3.8+**.

### Запуск
В терминале перейдите в папку проекта и выполните:

```bash
python3 bot.py
```

Для завершения диалога введите `выход`, `exit` или `q` (либо нажмите `Ctrl+C`).

### Запуск тестов

Для проверки сопоставления вопросов и пограничных случаев:

```bash
python3 test_bot.py
```

## 💬 Пример работы

```text
============================================================
🤖 Привет! Я FAQ-бот репетиции хакатона.
Я могу ответить на вопросы о времени, команде, треках, сдаче и призах.
Для выхода введите 'выход', 'exit' или 'q'.
============================================================

Вы: Во сколько старт и сколько продлится?
Бот: Репетиция проходит сегодня с 18:00 до 21:00 (длительность — 3 часа).

Вы: Сколько человек может быть в группе?
Бот: В команде может быть от 2 до 5 человек. Ограничений по ролям нет.

Вы: Какие направления есть?
Бот: Доступны три трека: AI/ML сервисы, Web & Mobile разработка и FinTech.

Вы: Куда отправлять ссылку на гитхаб?
Бот: Проект сдается в виде ссылки на публичный репозиторий команды на GitHub в чат организаторов до 21:00.

Вы: Что дадут победителям?
Бот: Победители получают фирменный мерч, памятные дипломы и фаст-трек в основной этап хакатона.

Вы: Какая сегодня погода на улице?
Бот: К сожалению, я не знаю ответа на этот вопрос.

Вы: exit
Бот: Удачи на репетиции! До связи.
```
